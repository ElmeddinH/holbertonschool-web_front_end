# Flexbox

Holberton School front-end project — converting a float-based layout to Flexbox.
Techium website is progressively refactored from `float` to `display: flex`
across 14 tasks (0–14).

## Files
- `0-index.html`, `0-styles.css` — Add display flex to `.row`
- `1-index.html`, `1-styles.css` — Add semantic classes on sections
